**Featured Work**
Root-Causing a Currency Default Bug in a Client-Facing Grid Layout

A client submitting a research funding request in EUR found that a related field defaulted to USD on amendment, instead of retaining the original currency. Our Tier 2 team's recommended fix — exporting and re-importing the grid layout, which had resolved a similar issue in our lower environment — didn't fix it here.

Rather than escalating without a resolution, I compared the field logic side by side between the working and non-working environments and traced the issue to extra leading whitespace silently breaking the currency reference. I deleted and rebuilt the field logic cleanly, which resolved the issue and restored the correct default behavior. This also gave the team a more precise root cause to watch for on other fields going forward.

Skills demonstrated: environment comparison, configuration debugging, root-cause analysis, client communication

**Automating a Manual/Paper-Based Trade Form Process**

A recurring internal process relied entirely on paper: individuals hand-filled a trade form, physically delivered it to the Director of Finance for invoicing, and then I was notified to fulfill the request — all tracked in a spreadsheet I maintained by hand. In practice, most forms weren't delivered until tournament week itself, which was the worst possible time for added manual work.

I built a digital replacement using Microsoft Forms and Power Automate: submitting the form automatically emails both myself and the Director of Finance with the full trade details, auto-populates a tracking spreadsheet, and assigns a unique tracking number to each request. This eliminated the paper hand-off entirely, removed the tournament-week bottleneck, and gave us a reliable, searchable record of every request. The same pattern was later reused to build a separate ticket request form for a different category of requests.

Skills demonstrated: process automation, workflow design, stakeholder needs analysis, low-code development
